- events: `GET /events`, `GET /events/:id`, `POST /events/:id/feature`, `POST /events/:id/unfeature`,
  `POST /events/:id/cancel`, `POST /events/:id/distribute-shards`
- groups: `GET /groups`, `GET /groups/:id`, `GET /groups/:id/members`, `GET /groups/:id/ledger`
- reports: `GET /reports`, `GET /reports/:id`, `POST /reports/:id/action`
- shards: `POST /ranks/recalculate`
- config: `GET /config`, `GET /config/:key`, `POST /config/:key`
- subs: `GET /subs`, `GET /subs/:id`, `POST /subs/:id/override`, `POST /subs/:id/revoke`

**Reserved (post-MVP):** `/api/v1/promotor/*` and `/api/v1/venue/*` → **501** `{"error":"not implemented"}`.

### Decisions

- **Auth placeholder:** `requireAdmin()` compares the `Authorization: Bearer` token to `ADMIN_API_KEY`
  (constant-time compare). Fails closed (401) when the env var is unset. Same header shape as the
  future JWT middleware, so S-06/M-21 only swap the middleware body.
- **Error mapping:** validation → 400, ops "not found" → 404, everything else → 500 with generic
  `{"error":"internal error"}` — internals logged server-side, never leaked.
- **Params:** identical validation to the CLI (`oneOf` enums, `parseDate` YYYY-MM-DD, positive ints,
  UUID for delete) so API and CLI reject the same inputs.
- **Audit identity:** `SUPABASE_ADMIN_USER_ID` (same var as the CLI) until JWT subject replaces it.
- **Health:** `ops.HealthCheck` reused; I-43 changed it to return an error on DB failure mid-flight —
  handler adapted (degraded JSON, still HTTP 200).
- **Version:** `serverVersion = "0.1.0"` in `/api/v1/health` (placeholder doc §3.1 says TBD by I-41).

## MISTAKE blocks

### MISTAKE 1 — `go mod tidy` removed gin after `go get`
`go get gin && go mod tidy` in a session where no code imported gin yet → tidy dropped the
dependency. Fix: re-added after the test files imported it. Lesson: add the dep *after* code
references it, or verify go.mod still contains it.

### MISTAKE 2 — stale locks on go.mod/go.sum
Held go.mod/go.sum from the second `go get` round until the `list` review caught them; released
immediately. Lesson: release in the same command chain as the go get.

### MISTAKE 3 — test harness bugs confused with implementation bugs
`assertStatus` dereferenced `w.Result().Request` (nil in httptest recorder) and `decodeJSON`
couldn't parse array bodies; the `:id` GET tests used an empty-array stub (correctly 404-ing
through the ops not-found path). Fixed the harness, kept behavior.

### MISTAKE 4 — delete validation test used a valid UUID
`POST /users/<valid-uuid>/delete` correctly returned 200; added a `not-a-uuid` case for the 400.
