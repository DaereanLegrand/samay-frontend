## Decisions made and why

1. **purchases_flutter `^10.8.0`** — the version I-23 removed (the I-10
   freezed-compat bump already landed it); resolves cleanly with Flutter
   3.44.1/Dart 3.11.4 and keeps the analyzer 13.0.0/freezed 4.0.0-dev.3 chain
   untouched (no transitive freezed pin in 10.x).
2. **Driver seam, not direct plugin calls in the service** — RSDK requires
   `Purchases.configure` in `main.dart` (not here), and tests need to exercise
   the configured path without platform channels. The `RevenueCatDriver`
   abstraction (mocktail-able) keeps the plugin behind one file; stub mode
   never imports it.
3. **`NotConfiguredError` in `app_error.dart`** — `AppError` is `sealed`;
   subclasses must live in the same library, and the mission required a typed
   error. It also maps through `toAppError()` for free.
4. **`isStubMode` sync getter drives the UI** — deterministic for tests and
   flips automatically once a key is present (RSDK wiring needs no screen
   changes).
5. **Prices formatted as `S/ 19.99`** — `es_PE`'s native currency format puts
   the symbol after the number with a comma decimal (`19,99 S/`); the spec
   display style (`S/. 19.99`) uses symbol-first + dot, so the decimal digits
   are formatted via `en_US` and prefixed. Unit-tested.
6. **Current-tier badge reads `AuthState.user['subscription_tier']`** (with a
   `user_metadata` fallback) per mission. Today the GoTrue user JSON does NOT
   carry the tier — the RCBH client fallback (`getCustomerInfo` sync on open,
   SBAS) is the intended end-to-end source (documented in the screen).

## MISTAKE / gotcha

- **`es_PE` currency format surprise** — I initially asserted `S/ 19.99` with
  `NumberFormat.currency(locale: 'es_PE')`, which renders `19,99 S/` (symbol
  after, comma decimal). Verified in isolation before wiring, then implemented
  the explicit `S/ ` + `en_US`-digits form. Tests caught it — always verify
  locale output before hardcoding expectations.
- **`purchaseProduct` deprecated in 10.8.0** — `dart analyze` flagged it; the
  modern API is `Purchases.purchase(PurchaseParams.storeProduct(...))`, which
  requires fetching the `StoreProduct` first (`Purchases.getProducts`).
- **`const NotConfiguredError()` impossible** — `AppError` (sealed, abstract
  getter only) has a non-const implicit constructor; the subclass constructor
  must not be `const` (analyzer: `const_constructor_with_non_const_super`).
- **Lock contention** — the l10n files/TODO.md/app_router.dart/app_router_test
  /runner.sh are hotly contested (I-56→I-58→I-57 chain on l10n; I-59 on
  app_router; I-60 on app_router_test/runner.sh/TODO.md). Held up to ~1h per
  file; semaphore rules observed (waited, never barged). Background acquires
  (nohup) used to parallelize the wait.
