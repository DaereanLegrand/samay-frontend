## 1. What was fixed

### 1.1 Nonexistent RPC — `lib/core/services/event_service.dart`
`likePhoto()` called `client.rpc('increment_photo_likes', ...)` after the
likes-row insert, but **no such function exists in any migration**
(verified: `rg increment_photo_likes supabase/` = 0 hits). The DB already
maintains `event_photos.likes_count` via `photo_likes_count_trigger`
(AFTER INSERT OR DELETE ON `event_photo_likes`, full_schema.sql §5.5,
re-declared in `20260809000001_harden_rls_search_path.sql:170`). Removed the
RPC call; the insert alone is now the contract (comment documents why).

### 1.2 CreateGroupScreen upload path — `lib/features/groups/create_group_screen.dart`
Applied I-22's blocked call-site swap:
- `StatefulWidget` → `ConsumerStatefulWidget` (needs `ref`).
- Cover upload block → `ref.read(mediaServiceProvider).uploadGroupCover(bytes)`
  (which compresses via `ImageProcessor.compressBytes` — I-22 already wired it
  into `uploadGroupCover`; the stored object is always `.png`).
- `SupabaseService.instance.getUserGroupCount()` / `.createGroup(...)` →
  `ref.read(groupServiceProvider)...` (same behavior: count check → upload →
  createGroup).
- Added the `GalleryPicker` injectable seam (same thin-wrapper pattern as
  `EditProfileScreen.galleryPicker` — I-36) so the upload path is widget-testable.

## 4. MISTAKE blocks

- **MISTAKE (FakeAsync file IO):** the first create-with-cover widget test
  hung indefinitely — `Directory.systemTemp.createTemp` + real file IO never
  completes inside `testWidgets` (FakeAsync zone). Fix: create the temp PNG
  inside `tester.runAsync(...)`, then hand the screen an **in-memory**
  `XFile.fromData(bytes, path: realPath)` — `readAsBytes()` is synchronous
  (no fake-async stall) and the real file at that path keeps the cover
  preview's `Image.file` decode error-free.
- **MISTAKE (null-assert precedence):** `await tester.runAsync(...)!` applies
  `!` to the *Future* (a no-op — `Future<T?>` isn't itself nullable) leaving
  `Directory?`. Correct form: `(await tester.runAsync(...))!`.
- **MISTAKE (GoRouter stack):** sibling routes with `initialLocation:
  '/create'` gave GoRouter a one-entry stack — `context.pop()` threw
  `GoError: There is nothing to pop` (caught by `_create`'s handler, tests
  still passed but logged ERROR noise). Fix: nested route
  `path: '/' → routes: ['create']`.
- **MISTAKE (mocktail):** `any()` used as a *named* arg without the named API
  (`params: any()`) throws "argument matchers can only be used as an argument
  for the very method being stubbed"; correct form is
  `any(named: 'params')`.
- **MISTAKE (typed resolution):** stubbing `insert` with
  `_ResolvingFilter<PostgrestList>(null)` casts `null as PostgrestList` at
  await time (non-nullable) → `type 'Null' is not a subtype`; use
  `_ResolvingFilter<dynamic>(null)` for statement-style calls.
