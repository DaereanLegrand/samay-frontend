## Decisions

- **`shellIndexFor` returns 0 for unknown locations** — mirrors the old fallback
  (`currentIndex = 0` default). Auth/non-shell locations never reach the shell builder, but the
  pure function is total for safety.
- **Index mapping now uses `RoutePaths.*` constants** (`location.startsWith(RoutePaths.mainGroups)`)
  instead of the raw `'/main/...'` strings left by H-02 — same values, closes the noted H-02
  follow-up ("trivial future follow-up" in the H-02 log) without changing behavior.
- **`selectedIcon` is data-only for now** — `BottomNavigationBarItem` keeps only `icon:` so the
  rendered tab bar is byte-identical to the pre-extraction app (NAV-05 fix must not change
  visuals; the theme also forces icons-only rendering via `showSelectedLabels/UnselectedLabels:
  false`). `selectedIcon` is asserted non-null/≠icon in tests and is ready for U-17
  (Juega main-shell/tab flow alignment) to wire `activeIcon:`.
- **Labels verified via widget-config inspection + a label-showing theme in tests** — with
  `showSelectedLabels/showUnselectedLabels: false` the label `Text` stays in the tree wrapped in
  `Visibility.maintain` (verified in Flutter 3.44.1 `bottom_navigation_bar.dart`), so
  `find.text` would still find them; the tests use an explicit theme override
  (`showSelectedLabels: true, showUnselectedLabels: true`) to assert label rendering
  deterministically.
- **Navigation test uses a real `GoRouter` with a stub shell route** (5 stub child routes) so
  `context.go` is exercised end-to-end without touching Supabase/AuthGuard (no
  `Supabase.initialize` needed — the H-01 harness is not required for this file).
- **Lint discipline**: `sort_child_properties_last` (child must be last named arg) applied in
  both new file and the router edit; `dart analyze` must stay 0 errors / 0 warnings from my files.
