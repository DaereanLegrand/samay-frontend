### 2. Thin facade — `lib/core/services/supabase_service.dart`
- Rewritten from 939 lines to a delegating facade: same public API (`client`,
  `auth`, all 60+ methods), header documents the decomposition + STOP-100
  deletion plan. All delegates are `async` so error semantics match the old
  monolith exactly (sync throws → failed futures).
- `callEdgeFunction` kept on the facade (future `ApiService`; I-38 prekey RPCs
  go through `client.rpc`, not this).

### 3. DI wiring — `lib/core/providers/service_providers.dart` (new)

  overridable in tests). Cross-deps: AuthService→ConfigService,
  ShardsService→ConfigService, ChatService/NotificationService→RealtimeService.

## Decisions & rationale

1. **Services stay in `lib/core/services/`** for now — moving into
   `lib/features/*/services` is M-23's structural pass.
2. **`MediaService` name** — `storage_service.dart` already owns
   SecureStorage/Hive; `MediaService` is the storage/media service.
3. **Facade delegates are `async`** — the old monolith's methods were all
   `async`; non-async `=>` delegates threw synchronously when a `late final`
   service touched `Supabase.instance` before init (broke
   `GroupMembersScreen renders loading state first`).
4. **`ChatService` E2EE seam** — documented `sendEncrypted` extension point so
   I-38 adds encryption without touching call sites (E2EE-ARCHITECTURE.md §12.2
   step 3 names `chat_service` as the seam).
5. **`supabaseServiceProvider` kept** — I-09 added it as the test seam; keeping
   it preserves their work and gives feature agents a facade provider while
   migrating. Not removed to avoid breaking other agents' in-flight tests.

## MISTAKE blocks

- **MISTAKE (mocktail):** `when(() => builder.then(any(), onError: any(named: 'onError')))`
  on a Postgrest builder never matches the real `await` (named matcher vs
  omitted arg), and `thenReturn` rejects Future-implementing values while
  leaving `_whenCall` stuck (cascading "Cannot call `when` within a stub
  response"). mocktail cannot stub `then` on classes implementing `Future` at
  all. **Fix:** real `_ResolvingFilter<T> extends PostgrestFilterBuilder<T>`
  overriding `then` — resolves without network, verified by minimal experiment.
- **MISTAKE (facade semantics):** initial facade delegates were expression-
  bodied (`=>`) — a `late final` service touching `Supabase.instance.client`
  threw *synchronously*, changing async-error timing and breaking the
  "renders loading state first" widget test (spinner never shown). **Fix:**
  every Future-returning delegate is now `async =>` (63 delegates).
