## Decisions made and why

- **Canonical = `app_es.arb`** (not the Flutter default `app_en.arb`): Samay's
  market is Peru; Spanish is the source of truth, English the translation.
  I-15 must copy the exact es wording so there are zero visual diffs.
- **`locale: Locale('es')` pinned in `MaterialApp`** in addition to
  es-first `supportedLocales`: guarantees Spanish rendering regardless of
  device locale (matches "app stays Spanish-default").
- **`nullable-getter: false`**: generated `of(context)` is non-null —
  production code stays terse; the only cost is that callers must have
  delegates (all real trees do).
- **camelCase keys with feature prefixes** (e.g. `commonCreateAccount`,
  `authOtpSentTo`): gen-l10n requires ARB keys to be valid Dart identifiers —
  dotted keys (`common.ok`) are rejected ("Resources names must be valid Dart
  method names"). The logical grouping (auth./profile./friends./groups./
  common./errors.) is preserved via the prefix.
- **`preferred-supported-locales: [es]`** added beyond the mission's minimal
  l10n.yaml list so the generated `supportedLocales` is `[es, en]` (mission:
  "supportedLocales (es first)").
- **Test harnesses updated** to pin `locale: Locale('es')`: `find.text` finds
  rendered Spanish strings; without the pin, the test environment's `en_US`
  locale resolves `en` and the widget renders English (seen live during dev).
- **`errors.*` and service `Exception` strings are in the ARB already** so
  I-15 can wire them (they live in `AppError` classes with no context — I-15
  decides the mechanism; likely error codes).
- **Duplicates are intentional**: 'Volver'/'Cancelar'/'Amigos' etc. exist in
  both `common.*` and feature namespaces where the feature UI uses its own
  wording; I-15 may consolidate.

## MISTAKE

- **Dotted ARB keys are invalid.** First ARB draft used `"common.ok": …`
  (logical grouping). `flutter gen-l10n` failed hard: "Resources names must be
  valid Dart method names". Fixed by rewriting all 229 keys camelCase
  (`commonOk`, `authOtpSentTo`, …). Lesson: ARB key = generated Dart getter
  name — no dots, no dashes.
- **Test harness locale.** First harness edit added delegates but no
  `locale:`; tests failed with "Found 0 widgets with text 'Crear cuenta'"
  because the test platform locale (`en_US`) resolved the `en` bundle.
  Pinning `locale: Locale('es')` in the harnesses fixed it.
- **`synthetic-package: false` is deprecated in Flutter 3.44** ("no longer has
  any effect"). It is mission-required, harmless (warning only, exit 0), and
  files ARE generated into `lib/l10n/` as intended; keep until the orchestrator
  says otherwise.
