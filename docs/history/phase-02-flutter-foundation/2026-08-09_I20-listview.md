## Decisions & rationale

1. **Sealed descriptor class + switch in `itemBuilder`** (matching the repo's
   existing sealed-class idiom — `route_extras.dart`, `app_error.dart`):
   keeps the two-section layout readable and only row *data* is materialized
   up-front; widgets are built lazily, which is the actual PERF-01 win. The
   interrupted session's factory-constructor variant failed the analyzer
   (factory methods are not types for switch patterns) — replaced with
   concrete subclass constructors.
2. **Plain `ListView(` as the guard pattern**: `ListView(children` literally
   never occurs (line breaks), so that literal would be a no-op guard.
3. **Did not convert fixed forms to `SingleChildScrollView`+`Column`**: out of
   PERF-01's scope; restyling agents (U-07/U-09/U-11) own those screens next.
   Kept as documented allowlist entries — smaller diff, fewer merge conflicts.
4. **Requests-screen `_ActionPair`**: genuine 2× duplication within one file
   (mission criterion); modest extraction, no behavior change.
