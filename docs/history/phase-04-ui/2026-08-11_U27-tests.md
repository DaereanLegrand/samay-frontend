## 6. MISTAKE blocks

- **Dropped `main()`'s closing brace (caught by the compiler):** the first
  structural edit that removed the `SamayThemeExtension` group left the
  final `}` of `main()` out — "Can't find '}' to match '{'". Restored. This
  is the U-23 MISTAKE class (structural test-file edits); lesson repeated:
  verify the file's brace balance after group removal, not just the edited
  region.
- **Non-existent `TextTheme.otpInputText` getter:** the otp token-only pin
  first asserted `AppTypography.textTheme.otpInputText == null` — `textTheme`
  is a `TextTheme` (no such role). The point of the pin is that otpInputText
  is a §3.3 *token*, not a composed role; reworded to assert the token's
  30px + no-role-collision.
- **`unnecessary_non_null_assertion` ×2 (analyzer):** `ThemeData.segmentedButtonTheme`
  is non-nullable in Flutter 3.44.1 — the `!` in the new tests was noise;
  removed (both in app_theme_test and the repointed restyle test).

## 7. Decisions made and why

- **Consolidate, don't delete.** Every removed assertion's coverage survives
  in its canonical suite (token values → `app_typography_test`/`app_colors_test`;
  context resolution → `theme_extension_test`); the theme suite now asserts
  *composition* (tokens → theme) instead of re-asserting token values — the
  layer-boundary test contract.
- **Table-driven theme test over per-role tests:** one 14-role table with
  `reason:` per field keeps triage quality (the failing role/field is named)
  while killing 8 near-identical bodies — the U-02 typography-table pattern
  applied at the theme layer.
- **SegmentedButton promotion is in-scope consolidation, not gold-plating:**
  the inline screen style duplicated the §5.4 chip treatment; U-09's handoff
  names U-27 for the promotion; `styleFrom`'s fromMap internals keep the
  equality contract (SDK source verified + green persistence tests). The
  restyle test keeps asserting the same resolved per-state values — from the
  theme now.
- **No widget-level shimmer-duration pin:** reading `_VShimmerState._controller`
  would need `dynamic` state access — the §4.5 token test pins the value and
  `v_shimmer.dart` consumes `SamayDurations.shimmer` (grep-verified);
  widget tests already pin the sweep/reduced-motion behavior.
- **No test-file moves:** the 4 flat `*_screens_test.dart` files are
  pre-U-series placement (documented note only); moving them risks
  campaign-wide path churn for zero coverage gain — U-28 may do it if the
  feature-folder convention is enforced repo-wide.
