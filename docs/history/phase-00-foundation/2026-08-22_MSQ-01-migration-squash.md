## Decisions & rationale

- **Canonical = replayed-from-migrations state**, then live DB hot-fixed to
  it (additive: 2 perf indexes, 4 function grants, 2 ADP lines). Live and
  replay were proven identical before authoring anything.
- **Intentional deviation (1 line):** baseline *drops*
  `FOR ROLE supabase_admin … FUNCTIONS TO anon` default privilege that the
  historical state carried inertly. pgTAP #376 (S-03/S-17 lineage) forbids
  it; the old pile could never strip it because #27 ran unprivileged. The
  privileged tier finally enforces the intended hardening.
- **Platform boundary respected:** no `auth.*`/`storage.*` internals are
  recreated; publications/buckets/cron carried as guarded/idempotent glue.
  `auth.jwt()` proved to be GoTrue-provided at boot (earlier "missing" was a
  bare-container artifact) — no shim shipped.
- **Orphaned data dropped from seed:** 17 public.users rows without auth
  accounts (old curl-test leftovers), 7 non-tester groups + dependents, and
  one 43-message chat referencing a deleted group `0a11ecc1…` (no
  participants; invisible to the app). Recoverable until next manual reset
  of 54382 via git history + MinIO volume backup.
- **Storage blobs** are NOT in SQL seeds. Backup taken:
  `/tmp/samay_squash/minio_testing_backup.tgz` (6.1M,
  `samay-testing_minio-data`). Restore after any future reset by extracting
  over the fresh MinIO volume.
- **opt-012 was broken before this work** (post-baseline addition): collided
  usernames with opt-011 fixtures + missing return=representation. Fixed as
  part of suite-green mandate.

## MISTAKE block (searchable)

- **MISTAKE (MSQ-01):** Makefile migration loops used `psql || true`-style
  swallowing (no error propagation), so `storage_buckets.sql`'s privileged
  policy section silently never applied on ANY fresh init for months.
  Lesson: static gates must probe failure paths, and appliers must abort
  loudly (apply_migrations.sh uses `set -euo pipefail` + ON_ERROR_STOP=1).
- **MISTAKE (MSQ-01):** trusted `pg_stat_user_tables` estimates during recon
  (shard_ledger "1 row" → actually 17). Always COUNT(*) for decisions.
- **MISTAKE (MSQ-01):** three separate regen cycles lost manually-authored
  infra files before scripting `assemble.sh`. Any generated+manual hybrid
  tree needs ONE assembly entrypoint from day one.
