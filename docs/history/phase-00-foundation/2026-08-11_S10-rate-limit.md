## Findings

1. **Kong has no rate-limit plugin** (MEDIUM): the gateway doesn't throttle
   PostgREST/Realtime/Storage; protection = GoTrue auth limits (login/OTP/
   refresh) + RLS. Once edge functions ship, gate abuse-prone endpoints with
   the Kong rate-limiting plugin (per-consumer + per-IP) or the
   `security.*` app_config thresholds.
2. **app_config abuse thresholds are inert today** — the FLMT spec's
   enforcement points (event creation, invites, QR rotation/validation) all
   need EEDG. Tracked as the FLMT dependency chain (cross-references.md).
3. Signed-URL generation (S-09) + `fetch_prekey_bundle` (OPK exhaustion) are
   unrate-limited — both become bounded when the Kong plugin lands.
