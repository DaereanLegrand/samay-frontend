## Decisions made and why

1. **`.opencode/opencode.json` as the config filename** — empirically
   verified (not just doc'd): a probe config with `autoupdate: false`
   resolved via `opencode debug config`. Keeps everything under
   `.opencode/` per the mission; no root-level config file.
2. **Instructions over `AGENTS.md` alone** — AGENTS.md is auto-loaded as
   rules, but the explicit `instructions` array pins the four campaign docs
   (AGENT-RULES §1 semaphore, FILE-OWNERSHIP ownership map,
   DEVELOPMENT-WORKFLOW how-to) so the lock protocol is guaranteed in
   context regardless of opencode's rules-file discovery heuristics.
3. **Git mutations denied at the permission level** — the campaign's
   no-commit/no-push/no-destructive-git rules stop being advisory for
   AI-assisted sessions: `git commit/push/pull/am/cherry-pick/rebase/merge/
   reset/checkout/switch/clean/stash` are `deny` while `"*"` stays `allow`.
   The orchestrator remains the only committer (DEVELOPMENT-WORKFLOW §6).
   File-write arbitration stays **rule-driven** (the semaphore), not
   permission-driven — per the mission's pragmatic call; a permission map
   cannot encode per-file ownership.
4. **4 focused agents, not a Juega mirror** — Juega's 184 definitions were
   studied for *format* (markdown + frontmatter, mode/description/color,
   permission blocks in frontmatter) but Samay ships 4 agents matched to the
   campaign's actual gates: reviewer (the §5 sign-off checklist + validation
   matrix), security-check (secrets-check + check_ports + security docs),
   docs-verifier (V-series precursor), and `samay` (primary protocol agent).
   Subagents are read-only by construction (`edit`/`write` deny + bash
   restricted to their own gate commands) — they verify and report, they
   never mutate.
5. **`.agents/` NOT created (documented decision)** — Juega's `.agents/`
   holds portable skills (supabase SKILL.md packages) that already exist
   user-wide; project agent definitions live in `.opencode/agents/`. An
   empty `.agents/` would trip the structure_test no-placeholder-dirs
   invariant. The decision is written in `.opencode/README.md` and this log.
6. **Guards over docs** — the ARC-08/TOOL-05/L-02 state is pinned by tests
   (config parses, instructions reference AGENT-RULES, git commit/push
   denied, subagents shipped) so a future edit cannot silently break the
   contract (M-23/M-24 precedent).
