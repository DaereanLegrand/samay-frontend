## Findings

1. **CLI identity is operator-supplied** (`SUPABASE_ADMIN_USER_ID` / flag):
   audit attribution relies on the operator's environment + the service key
   staying server-side. Documented in the CLI spec; acceptable pre-release.
2. The future API server must resolve the caller against `admin_users`
   (JWT sub) instead of trusting a header (S-06/M-21 handoff, already the
   code comment's stated plan).
3. The image-default table grants on `admin_audit_log` etc. are cosmetic
   (RLS wins) — bundled into the S-03 column-grant cleanup.
