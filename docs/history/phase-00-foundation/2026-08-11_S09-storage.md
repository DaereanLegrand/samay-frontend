## Findings

1. **`MediaService.uploadEventCover` returns `getPublicUrl` for the PRIVATE
   `events` bucket** (`media_service.dart:50`) — the URL is not servable
   (M-08 flagged; S-09 confirms live in code). The event-detail/cover image
   would 404. **Fix path (report):** issue a signed URL (or a long-lived
   signed URL via a service-role RPC) for covers, or move covers to a
   public `event-covers` bucket with path-prefix ownership like avatars.
2. **No server-side signed-URL issuance** — the client calls
   `createSignedUrl` directly (standard storage-api path; the SELECT-RLS
   gate bounds it). When Edge Functions land (EEDG), a `sign_url` RPC
   (service_role) gives the same guarantee with rate limiting.
3. Signed-URL generation is unrate-limited (S-10 covers the DoS angle).
