## Decisions

- **Table-driven everywhere with `t.Run` subtests** (GO-10). Filter tests assert both presence
  (`want`) and absence (`notWant`) of sibling filters so filter leakage is caught.
- **Body capture added to the shared helper** instead of new per-file servers — one source of
  truth, backward compatible (existing tests only read Method/Path).
- **`newRoutingClient` dispatches on the exact path (no query)** and 500s on unexpected routes:
  multi-request flows (`GetEvent`, `CancelEvent`) fail loudly if the code hits the wrong table.
- **`CancelEvent` idempotency pinned:** an already-cancelled event must produce exactly ONE
  request (the status read) and zero writes — guards against pool double-return.
- **Invalid-action path pinned:** `ActionReport("explode")` returns an error and issues zero
  HTTP requests (validated before any client call).
- Mission item 3 (crud.go/query_builder.go coverage) is **N/A**: I-40's files had not landed at
  write time (verified `internal/db/` = client/models only, no `context.Context` in signatures).
  Tests are written against the current API per the mission's mid-flight rule; if I-39/I-40
  change signatures, `go test` will break loudly and the renames are mechanical.
