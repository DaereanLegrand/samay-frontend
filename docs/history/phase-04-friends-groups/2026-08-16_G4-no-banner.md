**Agent:** G4-no-banner · **USER FIX 4:** the group detail screen must not
render a hero banner (name + cover) above the tabs — the group name appears
ONLY at the top, next to the back arrow (AppBar title), on every group screen.

## Decisions made and why

- **Name placement rule:** the AppBar title is the only legal home for the
  group name on group screens (loading/error frames render no name — the data
  is not available yet).
- **Cover placement:** deleting the hero removed the only cover renderer, so
  the cover moved to the Info tab's first block (the task's "Info tab keeps
  the FULL info content — including cover").
- **`_minTabArea` vs analyze gate:** `dart analyze` flags an unreferenced
  private static const (`unused_field`, verified in a scratch file). Keeping
  the constant "exactly" while unused would break the 0-issues gate, so the
  constant now floors `_scrollableTabBody`'s `minHeight` — same value, same
  U-19 intent, no visual change.
- **Flow-test Chat-tab determinism:** the Chat tab's `groupChatIdProvider` is
  overridden to `null` in the new active-state test so the tab resolves to
  the honest placeholder (no `ChatThreadView`, no network).
