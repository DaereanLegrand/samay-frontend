## Decisions

- **Keep `BottomNavigationBar`, don't hand-roll a Row of InkWell items.**
  The orchestrator's preference; more importantly the a11y suite
  (`test/accessibility/a11y_test.dart` §4.1.2) and the smoke tests pin the
  framework semantics that the Material widget generates (labels announced
  even with `showSelectedLabels: false`, 5 button tiles, selected state).
  Rebuilding the bar would have required re-deriving all of that.
- **Custom strip instead of reusing `VGlass`:** `VGlass` draws a full 1px
  ring border + pastel glow + top-highlight sheen, designed for floating
  surfaces. The tab bar sits at the bottom screen edge — a ring border on
  the bottom edge would draw a fake seam under the home indicator. The strip
  reuses the same primitives (blur, white α0.05 sheen, gradient hairline) at
  ~40 lines.
- **Static glow, not `VGlowPulse`:** directive is explicit — the shell is
  chrome; a pulsing glow on the tab bar would compete with the screen's
  aurora. `glowShadows` at fixed α0.30 / blur 28 (directive's exact values).
- **`surface` α0.85 over the glass** (directive's exact theme line): the
  bar's own fill stays dark enough for icon contrast while the α0.15
  transparency lets the white sheen + blur read through. Over pure black the
  blur degrades to the sheen (documented `VGlass` behavior).
- **Hairline direction left → right** (white α0.25 → transparent): a clean
  asymmetric "light from the left" edge, per the directive's "α0.25 →
  transparent" gradient.

## MISTAKE blocks

- **MISTAKE (test-write):** the first version of the LUXE pin predicates
  used `(b.decoration! as BoxDecoration)` inside `is`-checked closures —
  `dart analyze` flagged `unnecessary_non_null_assertion` (3 warnings): the
  `w.decoration is BoxDecoration` guard already promotes, so `!` is dead.
  Fix: drop the `!`.
- **MISTAKE (avoided, structural):** wrapping `activeIcon` in `DecoratedBox`
  silently breaks the old `activeIcon is Icon` assertion pattern — caught
  before running, updated the pin with an unwrap helper instead of weakening
  it.
