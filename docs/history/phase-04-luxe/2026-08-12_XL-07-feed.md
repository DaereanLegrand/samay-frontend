## What was built

The feed screen (`lib/features/feed/screens/feed_screen.dart`) restyled to the
LUXE v2 design language. **Restyle-only**: every route, provider call, tap
target, ordering rule, refresh/empty/error state is byte-identical to the
I-58 FOUNDATION scope. Family: **cyan** (`AppGradients.familyOf('feed')`) —
NO PINK MAINS.

| Element | Before (DISCO) | After (LUXE) |
|---|---|---|
| Background | theme black | explicit `AppColors.discoBlack` Scaffold + ONE cyan `VAurora` ambient (`gradients: [AppGradients.cyan]`) |
| Hero "Samay" | `VBreathingGlow` (flat white glyphs, pink-ish glow stack) | `VDisplayText` — Playfair italic bold **UPPERCASE** (MAYUS enforced by the widget), cyan gradient glyph fill, glow-strong 3-layer pulsing halo (`soft: false`), one hero per screen |
| Radius chips | plain `VChip` (white border, white selected fill) | `VChip.accent(gradient: cyan)` — cyan vivid border/label, vivid fill when selected |
| Section dividers | `VDiscoDivider` (violet default after XL-14) | `VDiscoDivider(accentColor: discoCyan α0.5)` — the feed's cyan tint; flat because a 1px segment cannot carry a gradient |
| Featured cards | `Container` flat fill + `glowPink` 1px border | `VGlass` (sharp, `glowAlpha: 0.18` soft pastel glow, cyan gradient ring via `VGradientBorder`) |
| Featured badge | `VBadge.accent(color: glowPink)` | `VBadge.accent(gradient: AppGradients.cyan)` — pale watered cyan fill, mid-stop border, black label |
| Upcoming cards | `VCard` (flat `surface` fill + hairline) | `VGlassCard(gradient: cyan, glowAlpha: 0)` — sharp hairline glass with the cyan ring; glow reserved for the featured carousel |
| Empty / error / loading / pull-to-refresh | `VEmptyView` / `ErrorView` / `VSkeletonDetail` / `RefreshIndicator` | unchanged |

**Foundation defect fixed (coordinated via lock, see Decisions):**
`lib/shared/widgets/glass/v_glass.dart` — the `VGradientBorder` ring layer
(`Positioned.fill`, transparent fill, `SizedBox.expand`) was painted ABOVE
the content and absorbed every pointer hit on glass surfaces. First consumer
(feed) surfaced it as "tap missed" warnings in widget tests. Wrapped the ring
in `IgnorePointer` — rendering byte-identical, hit-testing fixed.

## Decisions

- **`VGlass` primitive for the featured card, not `VGlassCard`.** The
  featured card keeps a full-bleed 120px cover; `VGlassCard`'s fixed 16px
  padding would inset the cover. Same sharp glass + cyan ring + glow,
  `padding: EdgeInsets.zero` — documented in the card's doc comment.
- **List cards are `VGlassCard(glowAlpha: 0)`.** "Sharp, hairline" is the
  directive for the list; the soft glow belongs to the featured carousel
  only (glow discipline — luxury = scarce glows).
- **Divider accent = `discoCyan` at α0.5**, per the directive's "cyan α0.5
  or keep neutral" option — the cyan vivid end watered for chrome.
- **`VChip.accent` carries the family hue flat** (its vivid end): a
  `FilterChip` `side` cannot be a gradient; the gradient family resolves
  the accent color, documented in the chip row doc comment.
- **Hero is 40px (displayMedium) `soft: false`** — the 3-layer glow-strong
  halo (was `displaySmall` glow-strong in DISCO; same halo class, bigger
  voice for the landing hero).
- **VGlass ring → `IgnorePointer` (XL-02's file, coordinated):** pure chrome
  must not intercept gestures; `SizedBox.expand` carries no interactivity,
  so the wrap cannot change behavior — only hit-testing (which was broken).
  Held the file lock, ran the glass suites, noted in this report.
- No new tokens needed: cyan family + pastel/`discoCyan` already shipped by
  XL-01/XL-14.

## Sources (web research, 2026-08-12 — all fetched & verified)

- **2026 feed/luxury palette:** "8 color scheme trends in mobile app design
  2026" (Envato Elements, 2026-02-05) — dark mode + vibrant accents,
  gradient combinations "back with depth", soft-tech pastels, glass-morphism
  social feed examples; supports black-bg + cyan-glow + glass cards.
  https://elements.envato.com/learn/color-scheme-trends-in-mobile-app-design
- **Featured carousel:** "Carousel Usability: Designing an Effective UI for
  Websites with Content Overload" (Kara Pernice, NN/g — reviewed 2026-08-07):
  ≤5 frames, static (no auto-forward), bleed the next card to signal more —
  the feed's static horizontal carousel with peeked next card follows this.
  https://www.nngroup.com/articles/designing-effective-carousels/
- **No auto-forwarding / static hero:** "Auto-Forwarding Carousels and
  Accordions Annoy Users and Reduce Visibility" (Jakob Nielsen, NN/g).
  https://www.nngroup.com/articles/auto-forwarding/
- **Dark mode trade-offs:** "Dark Mode vs. Light Mode: Which Is Better?"
  (Raluca Budiu, NN/g) — dark-mode a11y nuance behind the always-black
  directive. https://www.nngroup.com/articles/dark-mode/
- **Glass blur:** "backdrop-filter" (CSS-Tricks Almanac) — blur applies to
  the element's backdrop (the VGlass `BackdropFilter` rationale).
  https://css-tricks.com/backdrop-filter/
- Gradient-CTA/pastel-accent sources re-cited from the XL-14 log (DesignRush,
  Onething, Softs, Eleken, GenDesigns, Coloruxlab — same campaign, verified).
