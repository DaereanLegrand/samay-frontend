### Screen anatomy (top → bottom)
- **Scaffold + AppBar** — unchanged (`chatTitle`); no hero exists, so no
  title duplication to remove (LUXE rule #8).
- **Backdrop** — `VAurora(gradients: [peach ×3], opacity: 0.04)`: one blob
  per anchor, all peach (monochrome family — no pink mains), at the α0.04
  floor so the thread stays content-first.
- **List** — unchanged state handling (`VLoadingView` / `ErrorView` /
  `VEmptyView` / pagination header). The older-page loader row stays a
  20px spinner (pinned by the U-21 allowlist + the screen test).
- **Bubbles** — `_MessageBubble`:
  - Own: `DecoratedBox(key: chatBubbleOwn-<id>)`, `AppGradients.peach.linear()`
    fill (pastel-first stops: vivid end #FF8A65 is 9.08:1 vs black — AA),
    radius **16**, subtle 3-layer peach halo (`glowShadows`, α0.12, blur 24),
    **black text**. The gradient carries the bubble signal — no border.
  - Peer: `VGlass(key: chatBubblePeer-<id>, gradient: peach, radius: 16,
    glowAlpha: 0.10)` — translucent white fill + peach gradient hairline +
    glow, white text.
  - Undecryptable placeholder: `mutedStrong` italic on both kinds (kept,
    §2.4 AA pin in the screen test + the a11y label test).
  - Both kinds radius 16 — the pre-LUXE `AppRadius.sharp` bubble decision is
    superseded (ORCHESTRATION-LUXE: radius 16–20 for liquid components;
    bubbles are the chat's liquid island).
- **Composer** — `VInput` (glass, untouched per directive) + send button =
  `VButton.emphasized(gradient: AppGradients.peach)`.
- **VThinkingDots wiring** — the provider exposes no typing/sending state
  (`ChatMessagesState` has no such flag), so per the directive the dots are
  wired into the **send-button loading state**: `_sending` flips around
  `send()`; while true the button keeps its peach face, drops the label and
  shows `VThinkingDots(color: discoBlack)`; `onPressed` is null while in
  flight (no double-send). `finally` clears the flag.

## Web research (cited)

1. **Liquid glass in chat** — 9to5Mac Liquid Glass guide
   (https://9to5mac.com/guides/liquid-glass/): WhatsApp rolled out Liquid
   Glass to the Chats list and is working on the **in-chat interface**
   (2026-05-01), and iOS 27 adds a transparency slider (2026-06-15) — the
   2026 direction is glass everywhere in messaging, with translucency kept
   tasteful. Applied: peer bubbles as glass surfaces with hairline rings,
   and the aurora kept at α0.04 so glass reads over pure black.
2. **Conversational UI / typing indicators** — IxDF "What are Chatbots?"
   (https://www.interaction-design.org/literature/topics/chatbots): modern
   conversational interfaces lean on AI-like affordances (thinking/typing
   cues) to signal in-flight work and keep the composer alive. Applied:
   `VThinkingDots` replaces the generic spinner as the send state — the
   "AI-thinking" accent the campaign mandates (directive #11), following the
   ORCHESTRATION-LUXE component vocabulary (`VThinkingDots` = chat-input
   typing indicator).
3. Apple HIG Materials page was JS-gated; the Liquid Glass research above is
   the citable record.

## Decisions & gotchas

- **No timestamps added**: the MVP screen renders no timestamps; the
  directive's "timestamps mutedStrong" is honored as a style rule for the
  next feature pass — adding new chrome would violate rule #8 (no redundant
  chrome) and the byte-identical behavior rule.
- **VGlass vs VGlassCard**: the directive names VGlassCard, but that
  convenience pins `radius: zero`; the liquid 16 corner requires `VGlass`
  directly with the same glass recipe (white α0.05→0.01 fill + hairline).
- **conventions_test allowlist**: the restyle moved the pagination loader's
  `CircularProgressIndicator` from line 154 → 184; updated the U-21
  allowlist entry (mechanical, caused by my owned-file edit).
