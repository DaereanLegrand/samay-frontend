## 4. Decisions

1. **VAurora = single violet family** (not the default 3-family) — the brief
   says `VAurora(violet)` and the screen family map owns violet for groups;
   rose never appears (even as micro-accent here — groups is a violet-only
   surface).
2. **Detail AppBar title removed** — LUXE directive #8 (no duplicated
   title): the hero `VDisplayText` is the single group-name moment.
3. **Invite AppBar action stays a TextButton** — `VButton` is
   `SizedBox(width: double.infinity)` by contract (§5.1); it cannot live in
   an AppBar action slot without breaking layout. The violet ring on the
   search field + glass rows carry the family; the invite flow is untouched.
4. **Cover picker stays neutral** (`surfaceAlt` + `border`) inside the glass
   form card — an empty image slot reads as empty; the card ring + CTA carry
   the violet accent.
5. **Glass sheets use `VGlass` (liquid 20), not `VGlassCard` (sharp)** —
   the vocabulary: radius 0 for cards, 16–20 for sheets; VGlassCard's zero
   radius is wrong for a modal.
6. **pumpAndSettle vs snackbars** — see MISTAKE below; the fix is bounded
   `pump()` calls in the 4 snackbar tests that keep a live aurora mounted.

## 5. MISTAKE blocks (searchable)

### MISTAKE XL-10-A — `git stash` clobbered the other agents' in-flight foundation
Ran `git stash` to check a pre-existing test failure; the stash captured the
whole worktree (other agents' locked files: `v_button.dart`, `v_chip.dart`,
`samay_durations.dart`, auth/feed/profile screens, …). `git stash pop`
conflicted on `.flutter-plugins-dependencies` (another agent's concurrent
`flutter pub get`) and aborted, leaving the tree at HEAD + my files only —
the LUXE foundation vanished → mass compile errors (`No named parameter
'gradient'`, `Member not found: 'auroraDrift'`).
**Fix:** recovered the dropped stash commit
(`git stash apply d3e93c9…` after `git checkout HEAD -- .flutter-plugins-dependencies`),
restoring all 116 modified files. No conflicts: the two side-edits made by
other agents during the window (minigames/party_finder/photos tests) were
unaffected.
**Lesson:** NEVER `git stash` in a shared multi-agent worktree. Use
`git diff`/`git show HEAD:file` for pre-existing-failure checks.

### MISTAKE XL-10-B — VAurora drift eats snackbars under pumpAndSettle
`VAurora`'s idle-safe drift is a 10s animation (by design, XL-04). Any
`pumpAndSettle` on a screen with a mounted aurora advances ~10s of fake
clock — which fires the SnackBar's 4s auto-dismiss timer, so snackbar text
assertions found nothing. Affected: 3 donate tests + 1 failed-kick test.
**Fix:** bounded pumps after the action
(`await tester.pump(); await tester.pump(const Duration(milliseconds: 400));`)
— deterministic, no settle-through. The valid-donation test was already safe
because the screen pops (aurora disposed).
**Note for downstream agents:** any test that shows a snackbar while its
screen stays mounted on an aurorized screen must use bounded pumps.
