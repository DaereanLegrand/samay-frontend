## Decisions

- **No display hero on any friends screen.** Directive: "only ONE hero
  moment per screen, prefer none on list screens — minimal". All four have
  AppBars → kept AppBar, titles stay Inter white via the theme; zero
  `VDisplayText`.
- **Aurora = mint ×3 (not the 3-family default).** VAurora's 2–3 blob
  geometry is kept by repeating the mint family on the three anchor
  positions; single-family so the friends family is unambiguous and no pink
  creeps in. α0.08 sits in the component's 0.04–0.10 "whisper" range.
- **Mint only on active elements.** Accept (`VButton.emphasized` mint face),
  add (`VButton.outlined` mint ring), pending badge, count badges. Decline,
  cancel, unblock and status readouts stay white theme TextButtons. The
  presence dot stays `statusOnline` cyan — presence is semantic, not a
  screen accent.
- **List rows keep the `ListTile` inside the card** so the R11/R12/R13 flow
  pins (row spinner, tab badges, refresh drags) keep resolving; the glass
  card's lg padding gives the generous tile look.
- **`Solicitado` → `SOLICITADO`** is a VBadge consequence (labelSmall
  uppercase voice), documented as the only behavior-file text pin touched.

## Web research (cited)

- IxDF — "Glassmorphism" (topic page, updated 2026): frosted glass =
  transparency + background blur + light borders + pastel/vivid colors;
  "soft and muted tones", "subtle gradients", "border highlights" and
  "minimalist and clean" directly motivated the sharp hairline glass tiles
  with pastel-ring borders and mint-only ambient.
  https://www.interaction-design.org/literature/topics/glassmorphism
- IxDF — "Top 10 UI Trends Every Designer Should Know": minimalism ("less
  is more") + dark mode + glassmorphism as the 2026-relevant triad; "use
  glass sparingly to avoid overwhelming" → one ambient aurora, not per-row
  effects. https://www.interaction-design.org/literature/article/top-10-ui-trends-every-designer-should-know
- DesignRush — "Mastering Gradient Design" (via XL-14's verified citation):
  contrast-first gradient surfaces; black-on-pastel-first mint fill for the
  accept button (pastelMint #D8FFEE start → black text ≈ 15:1).
  https://designrush.com/home/trends/graphic-design/mastering-gradient-design
- Search engines (Google/DuckDuckGo) were captcha-blocked; Bing returned
  only calendar results — cited sources above were fetched directly.
