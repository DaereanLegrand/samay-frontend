## Decisions

- **Map passthrough for catalog rows** (not a freezed model): matches the
  events feature precedent (I-54/I-55); avoids build_runner churn on the
  pinned freezed dev-branch for a display-only shape. The typed surface is
  the provider + `isCosmeticLocked`/`tierRank` pure helpers.
- **Typed purchase errors** over message sniffing: `purchaseCosmetic` now
  throws `InsufficientShardsException`/`TierRequirementException`; the
  provider translates to `CosmeticPurchaseException(failure)`; the screen
  maps failure → l10n key. (Message matching would have tripped the
  I-15 extraction guard, which flags Spanish literals in `lib/features/`.)
- **Equip toggle in the shop grid** (single screen) instead of a separate
  "Mis Cosméticos" screen: PLAN.md lists it separately, but the mission's
  shop scope (owned marking + equip in the grid) keeps one screen; the
  grid already carries all owned/equipped state.
- **`subscription_tier` added to the profile select** (1-line, file not in
  the assignment's lock list — acquired, changed, released, reported):
  without it the tier gate could never unlock for pro/vip users.

## Blockers / handoffs

  inserts directly into `shard_ledger`, but `shard_ledger` has NO INSERT

### The 7 failing tests — root cause + fix

All 7 failures were `test/features/cosmetics/cosmetics_shop_screen_test.dart`
RenderFlex overflows inside `_CosmeticCard` (6 of them) plus 1 stale test in
`test/features/profile_screens_test.dart` (see below).

**Root cause:** Flutter widget tests render with the **Ahem font**, where
every glyph is 1em wide. Fixed-width Row children in a narrow 2-column grid
card (~124px content width) then overflow: the "Adquirido" badge measured
≈128px and the "Requiere VIP" tier text ≈132px (Ahem) vs ~80px (Inter in
production). Two rows in `_CosmeticCard` were not overflow-safe:

1. **Header row** (`cosmetics_shop_screen.dart:342`, overflow 4.3px): badge +
   lock next to the type label. Key subtlety: **inflexible children of a
   `Row` are laid out with unbounded main-axis constraints** — a bare
   `Flexible(flex: 0)` + `FittedBox(scaleDown)` cannot clamp (verified against
   `RenderFlex._constraintsForNonFlexChild` in the pinned SDK and with a probe
   test). Fix: wrap the badge in `ConstrainedBox(maxWidth: 88)` + `FittedBox(
   scaleDown)` — the ConstrainedBox bounds the FittedBox, which then scales
   the badge down (single line, no wrap) instead of overflowing. Production
   visuals unchanged (badge ≈80px ≤ 88).
2. **Cost/tier row** (`cosmetics_shop_screen.dart:376`, overflow 58–72px):
   "Requiere VIP" was a fixed text after a `Spacer`. Fix: `Flexible` + `maxLines:
   1` + `TextOverflow.ellipsis` — the tier text now ellipsizes instead of
   overflowing (the `Text` data stays intact, so the `find.text('Requiere
   VIP')` assertion still matches).
